# AGENTS.md

## What this is

Home Stock Tracker HA is a standalone, read-only Home Assistant custom
integration for the Home Stock Tracker service. It is distributed as a HACS
custom repository and lives entirely under `custom_components/home_stock_tracker`.

## Read these for context

- `blueprint/context/project-overview.md` once generated by `$overview`
- `blueprint/context/coding-standards.md`
- `blueprint/context/ai-interaction.md`
- `blueprint/context/current-feature.md`

## Workflow

This repository uses the AI Blueprint workflow. Work one feature, fix, or
rollback at a time: create a spec with `$feature` or `$fix`, implement with
`$implement`, verify with `$check`, then archive and commit with `$complete`.
Use `$overview` after plan changes to generate the project overview. The shared
Codex skill adapters are in `.agents/skills/`.

## Commands

- Runtime: Home Assistant custom integration (Python)
- Test dependencies: `python3 -m pip install -r requirements-test.txt`
- Test: `python3 -m pytest -q tests`
- Test with the repository virtual environment: `.venv/bin/python -m pytest -q tests`

No standalone build, formatter, linter, or combined Verify command is currently
configured. Do not invent one; use `$tests` or `$ci` when the project is ready
to establish those checks.

## Guardrails

- Keep the integration read-only unless an approved feature explicitly changes
  that boundary.
- Never write configured API tokens to logs, entity attributes, diagnostics, or
  test output.
- Keep runtime files within `custom_components/home_stock_tracker/` and preserve
  HACS' required root layout.
- Update tests for behavior changes and retain unavailable-state behavior for
  connection, authentication, and payload failures.
