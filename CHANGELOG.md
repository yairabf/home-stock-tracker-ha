## 0.1.0 - Repository baseline

This baseline records the integration version present in the repository. It
does not claim that a GitHub Release has been published.

### Added

- Read-only Home Assistant config-entry integration for Home Stock Tracker.
- Coordinated polling for pending groceries, tracked inventory, and actionable
  low-stock recommendations.
- Three availability-aware count sensors with source-record attributes.
- HACS custom-repository metadata, installation guidance, and automated tests.
